## 📌 Tentang Timerin

**Timerin** adalah aplikasi utilitas Android berupa timer mengambang (*floating overlay timer*) yang dirancang khusus untuk mempermudah pemain game MOBA (seperti *Mobile Legends: Bang Bang*, *Honor of Kings*, dan game kompetitif lainnya) dalam mencatat dan memantau waktu *cooldown battle spell* musuh secara akurat tanpa perlu keluar dari arena pertandingan.

Dengan kontrol gestur sentuhan yang intuitif, pemain dapat langsung memulai hitung mundur waktu *cooldown* spell musuh (seperti *Flicker*, *Purify*, *Retribution*, *Sprint*, *Aegis*, dan lainnya) hanya dengan satu kali ketukan di layar.

## 🛡️ Jaminan Keamanan & Bebas Risiko Banned (100% Aman)

Timerin dirancang dengan mengutamakan kepatuhan terhadap kebijakan pengembang game dan standar keamanan sistem operasi Android:

* **Bukan Cheat atau Modifikasi Game:** Timerin adalah aplikasi stopwatch utilitas yang berjalan secara mandiri. Timerin **tidak memodifikasi file game**, **tidak membaca memori game**, dan **tidak menyuntikkan kode apa pun** ke dalam aplikasi game.
* **Tanpa Layanan Aksesibilitas (*No Accessibility Service*):** Timerin tidak menggunakan izin aksesibilitas untuk membaca layar atau mengambil data pertandingan.
* **Tanpa Perekaman Layar (*No Screen Capture*):** Timerin tidak merekam, memotret, atau menganalisis konten layar ponsel Anda. Seluruh fungsi dijalankan murni berdasarkan interaksi sentuhan manual pemain.
* **Kepatuhan Privasi Data (UU PDP No. 27/2022):** Data autentikasi akun Google diproteksi menggunakan infrastruktur keamanan Google Firebase. Timerin tidak menjual atau membagikan data pengguna ke pihak ketiga.
* **Mode Privasi Streaming:** Dilengkapi fitur sensor akun untuk menyembunyikan alamat email, nama, dan User ID (menjadi `****`) saat Anda sedang melakukan *live streaming* atau merekam layar.

## ✨ Fitur-Fitur Unggulan (Versi 1.0.1)

### 1. Floating Overlay Timer Fleksibel
* Overlay melayang di atas semua game dan aplikasi lain dengan performa ringan dan hemat daya baterai.
* Posisi overlay dapat digeser (*drag & drop*) ke titik layar mana pun sesuai kenyamanan navigasi jari Anda.
* Posisi awal overlay otomatis berada di bagian tengah layar saat pertama kali diaktifkan agar mudah diatur.

### 2. Kontrol Gestur Cepat
* **Ketuk 1x:** Memulai hitung mundur (*countdown*) timer spell.
* **Ketuk 2x:** Mereset timer seketika kembali ke durasi awal yang telah dikonfigurasi.

### 3. Kustomisasi Tampilan Lengkap
* **Jumlah Timer:** Pilihan 1 hingga 5 kotak timer simultan untuk memantau hingga 5 hero lawan sekaligus.
* **Pengaturan Durasi Kustom:** Setiap timer dapat diatur durasinya secara independen dari 5 hingga 600 detik (default 60 detik) melalui slider interaktif.
* **Transparansi Latar Belakang (Fitur Baru v1.0.1):** Tingkat transparansi warna latar belakang overlay dapat disesuaikan dari 10% hingga 100% agar pandangan visual pertempuran tetap jelas tanpa terhalang.
* **Ukuran Overlay:** Skala ukuran dapat diatur dari 50% hingga 100% menyesuaikan resolusi layar ponsel Anda.
* **Format Waktu:** Mendukung tampilan format detik murni (`90s`) atau menit dan detik (`01:30`).
* **Susunan Timer:** Pilihan orientasi kotak timer secara **Vertikal** atau **Horizontal**.

### 4. Umpan Balik Taktil (Getar 1 Detik)
* Memberikan umpan balik getaran fisik pada perangkat selama 1 detik saat hitung mundur timer berakhir sebagai pengingat instan bahwa spell musuh telah siap kembali.
* **Sinkronisasi Cerdas:** Sakelar getaran otomatis menyesuaikan dengan status perizinan haptik sistem perangkat pengguna.

### 5. Masa Coba Gratis & Langganan Terjangkau
* **Trial 24 Jam:** Setiap akun baru langsung mendapatkan masa percobaan gratis 24 jam penuh tanpa batasan fitur.
* **Langganan Hemat:** Hanya **Rp10.000 / 30 hari** melalui pembayaran QRIS manual.
* **Anti-Spam Cooldown:** Tombol segarkan status hak akses dan periksa pembaruan dilengkapi jeda *cooldown* 60 detik untuk kenyamanan jaringan.

### 6. Halaman Dukung Pengembang
* Halaman khusus untuk pengguna yang ingin memberikan donasi atau tip sukarela via barcode QRIS guna mendukung biaya server Firebase dan keberlangsungan pemeliharaan aplikasi.

## 🚀 Panduan Penggunaan

1. **Masuk Akun:** Buka Timerin dan masuk menggunakan Akun Google Anda.
2. **Izin Tampil di Atas Aplikasi Lain:**
   * Di halaman Beranda atau Pengaturan, ketuk tombol **"Izinkan Pengaturan Overlay Aplikasi"**.
   * Aktifkan izin pada menu pengaturan sistem Android agar timer dapat melayang di atas game.
3. **Konfigurasi Timer:**
   * Tentukan jumlah timer yang ingin digunakan (1-5).
   * Ketuk kotak durasi timer untuk mengatur durasi spell musuh (contoh: *Flicker* 120 detik, *Purify* 90 detik, dll).
   * Atur ukuran dan tingkat transparansi latar belakang sesuai kebutuhan.
   * Simpan pengaturan overlay dengan menekan tombol **"Simpan Pengaturan Overlay"**.
4. **Mulai Timer di Game:**
   * Tekan tombol **"Aktifkan Overlay Timer"**.
   * Buka game Anda, geser kotak timer ke posisi yang nyaman.
   * Ketuk 1x saat musuh memakai battle spell untuk memulai countdown, ketuk 2x untuk mereset.
   * Setelah selesai bermain, ketuk **"Matikan Overlay Timer"** di aplikasi Timerin.

## 📝 Catatan Rilis Versi 1.0.1

* **Fitur Transparansi Overlay:** Menambahkan slider pengatur opasitas latar belakang (10% - 100%) di bawah slider ukuran overlay.
* **Otomatisasi Sakelar Getaran:** Sakelar "Getar Saat Timer Habis" otomatis nonaktif jika umpan balik haptik sistem perangkat belum diaktifkan.
* **Tombol Izin Adaptif:** Tombol izin overlay dan haptik pada halaman Pengaturan otomatis menghilang jika status sudah diizinkan.
* **Tombol Aksi Beranda Dinamis:** Jika izin overlay belum diberikan, tombol utama beranda menampilkan status peringatan oranye *"Izinkan Overlay Aplikasi"* yang langsung mengarahkan ke dialog panduan izin.
* **Penyegaran 60 Detik:** Menyesuaikan durasi *cooldown* tombol segarkan status dan periksa update menjadi 60 detik.
* **Halaman Baru Dukung Pengembang:** Menyediakan menu terpisah khusus barcode QRIS donasi pengembang dengan fitur simpan ke galeri dan bagikan barcode.
* **Peningkatan Performa & Stabilitas:** Perbaikan pop-up masa aktif habis, optimalisasi rendering UI, dan penataan arsitektur kode.
